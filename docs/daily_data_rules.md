# 每日数据整理说明

这个项目的原始数据是一分钟期货行情。为了做论文核心回归框架的部分复现，需要先把一分钟数据整理成每日数据表，再在每日数据表上计算收益率和做回归。

## 1. 主要交易时间

六个期货品种的主要交易时间不同，所以不能全部使用同一个开盘和收盘时间。项目中使用的时间都按纽约时间理解。

| symbol | 品种 | 主要交易时间 |
| ------ | ---- | ------------ |
| ES.v.0 | E-mini S&P 500 | 09:30-16:00 |
| NQ.v.0 | E-mini Nasdaq 100 | 09:30-16:00 |
| GC.v.0 | 黄金期货 | 08:20-13:30 |
| CL.v.0 | WTI 原油期货 | 09:00-14:30 |
| ZN.v.0 | 10 年期美国国债期货 | 08:20-15:00 |
| 6E.v.0 | 欧元外汇期货 | 07:20-14:00 |

## 2. 每天取哪些价格

对每个交易日，项目会取几个关键时间点的价格：

- 前一交易日收盘价
- 当天开盘价
- 开盘后半小时价格
- 收盘前一小时价格
- 收盘前半小时价格
- 当天收盘价

这些价格用于计算论文中的日内收益率。具体到一分钟 bar 如何取价，见 `docs/price_time_rules.md`。

## 3. 收益率变量

整理好关键价格后，项目会计算以下变量：

```text
r_ONFH = 开盘后半小时价格 / 前一交易日收盘价 - 1
r_M    = 收盘前一小时价格 / 开盘后半小时价格 - 1
r_SLH  = 收盘前半小时价格 / 收盘前一小时价格 - 1
r_ROD  = 收盘前半小时价格 / 前一交易日收盘价 - 1
r_LH   = 当天收盘价 / 收盘前半小时价格 - 1
```

其中最重要的是 `r_ROD` 和 `r_LH`。项目主要检验的是：当天前面大部分时间的收益率 `r_ROD`，是否可以解释最后半小时收益率 `r_LH`。

## 4. 样本筛选

不是每个日期都会进入最终回归。项目会排除以下情况：

- 交易所假期
- 提前收盘日
- 缺少关键时间点价格的日期
- 没有可用前一交易日收盘价的日期
- 连续合约换月时，前一日收盘价和当天价格来自不同实际合约的日期

这些处理会减少样本数量，但可以避免用不完整或不一致的数据计算收益率。

## 5. 输出文件

整理后的每日数据表保存在本地：

```text
data/processed/{symbol}_daily_research_table.parquet
```

这些 parquet 文件来自 Databento 授权数据，不上传到 GitHub。GitHub 中只保留对应的 summary 和数据说明，例如：

```text
data/manifests/es_daily_data_summary.json
data/manifests/es_daily_data_notes.md
```
